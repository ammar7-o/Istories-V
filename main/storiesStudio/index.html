Complete JSON Format Example

{
    "title": "The Adventure Begins",                 // #any-text #shown-on-the-card
    "lang": "en",                                    // #en #fr #es #de #it #pt #ar #fa #ur #he #ru #tr #nl #pl #sv #el #hi #zh #ja #ko
    "level": "intermediate",                         // #beginner #intermediate #advanced
    "levelcefr": "A2",                               // #A1 #A2 #B1 #B2 #C1 #C2
    "cover": "🏝️",                                   // #emoji-char | #image-path-or-URL | #fa-class-like-fas-fa-book
    "coverType": "emoji",                            // #emoji #image #icon
    "content": [
        "Once upon a time, in a small village nestled between mountains...",   // #one-string-per-paragraph
        "The young hero set out on a journey filled with challenges.",         // you can use  as marked word
        "Each step brought new lessons and unforgettable experiences."         // you can use  for add images
    ],

    "author": "Your Name",                           // #optional #any-text
    "sound": "../sounds/story1.mp3",                 // #optional #path-or-URL #mp3 #read-along-audio
    "tags": [                                        // #optional #array-of-strings #used-by-search
        "adventure",
        "nature",
        "mystery"
    ],
    "dictionaries": [                                // #optional #array-of-file-paths
        "../../database/Dictionarys/story4.json",
        "../../database/Dictionarys/main.json"
    ],
    "translations": {                                // #optional #key-is-the-word
        "journey": "رحلة"                            // #short-form: translation-only
    }
}

Everything after // is a note listing every value the field accepts (the hashtags). The Copy button removes the notes for you.
