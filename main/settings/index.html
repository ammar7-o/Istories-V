IStories Settings

One place for every page

Settings

Theme, colours, reading, features and custom CSS — saved once and used across the whole app. Each page keeps its own settings panel too; changes here apply everywhere.

Appearance

Theme Light or dark mode
Accent color Primary colour used for buttons and highlights
Secondary color Used for accents, badges and gradients

Reading

Font family Reading font used in the story reader
Font size Text size in the story reader (1.0–2.0 rem)
Line spacing Comfortable or relaxed spacing between lines

Translation

Default translation language Language used when translating a tapped word
Auto-translate on tap Show the translation immediately when a word is tapped
Paragraph translation Translate a whole paragraph, not just single words
Hide translated words Hide words that already have a saved translation

Library & Quizzes

Show my stories Display the stories you created in the library
Show my quizzes Display the quizzes you created in the quiz page

Vocabulary & Speech

Pronunciation buttons Show the speaker button next to saved words
Auto-pronounce flashcards Read a flashcard aloud when it appears

Custom CSS

Each page has its own stylesheet. Pick a page, add CSS, and it is applied there with the same rules the in-page editor uses. Clearing only removes that page's CSS.

Data Management

Export my stories Download the stories you created (with their translations) as a JSON file
Delete my stories Permanently delete all stories you uploaded. This cannot be undone
Backup all data Download a backup of everything saved on this device
Restore data Import a previously saved backup file, replacing what is on this device
Delete all data Remove everything saved on this device — stories, words, quizzes and settings
